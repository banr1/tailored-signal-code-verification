# `ProofLib/Hoare`: Loops, Partial-Correctness Safety, and Extern / Libc Hooks

`ProofLib/Hoare/` provides the control-flow induction principles, partial-correctness safety adequacy theorems, generic extern-hook combinators, and `HookOk` witnesses for reusable C/Rust runtime hooks (`memcpy`, `memset`, `memmove`, `free`, `malloc`/`calloc`). Everything here is untrusted `Role::Proof`. The cross-binary hook definitions that `Spec.lean` files may use (`subroutineHook`, `subroutineHookEntry` / `subroutineHookExit`, `loadCodeMem` / `restoreCodeMem`) are trusted definitions in [`Arm64/Trusted/Spec/Hoare.lean`](../../Arm64/Trusted/Spec/Hoare.lean) (see [`Arm64/Trusted/README.md`](../../Arm64/Trusted/README.md)). The reusable allocator model (`ProofLib.Allocator`, `allocAt`, `libcFreeSpec`, `freeRegionSpec`) in [`ProofLib/LibcHooks.lean`](../LibcHooks.lean) is untrusted and may **not** be imported by `Spec.lean` files; a campaign spec that needs an allocator defines its own campaign-local allocator model (e.g. `<Campaign>.CallSiteAllocator` in `Examples/<Group>/<Campaign>/Spec.lean`) and bridges to these definitions in its untrusted `Proofs/`.

For interactive separation-logic loop tactics (`wp_loop_measure`, `wp_loop_list`, `wp_nested_loop`, `wp_loop`) and loop combinators (`SepWP.loop_fuel`, `SepWP.loop_measure`), see [`ProofLib/SepLogic/README.md`](../SepLogic/README.md) and `docs/dev/guides/writing-proofs.md` §4.

## Module Overview

### 1. `ProofLib/Hoare/Loop.lean` (`Role::Proof`)
Kernel-checked Floyd-Hoare cut-set and single-header loop induction rules over `Arm64.reaches_pc` and `Arm64.subroutine_ok`:
- `reaches_pc_cutset`: Well-founded induction on `measure : State → Nat` across an arbitrary cut-set invariant `Inv : State → Prop`.
- `reaches_pc_loop`: Single-header loop induction at `loop_pc` exiting to `exit_pc`.
- `subroutine_ok_of_loop`: Direct wrapper proving `subroutine_ok` via entry-to-header reachability + `reaches_pc_loop`.

### 1a. `SepWP` / `SepWPp` Loop Tactics & Continuation-in-Context CFG Combinators (`ProofLib/SepLogic/LoopTactics.lean`, `ProofLib/SepLogic/CFG.lean`, `ProofLib/SepLogic/WPp.lean`)
Direct loop combinators, tactic front-ends, and continuation-in-context CFG combinators for separation-logic (`SepWP`) and panic-aware (`SepWPp`) verification:
- **Loop combinators & tactic front-ends:** `SepWP.loop_fuel`, `SepWP.loop_measure`, `SepWP.loop_multi_exit`, `SepWP.loop_latch`, `SepWP.nested_loop` (`ProofLib/SepLogic/CFG.lean`), driven interactively by `wp_loop_measure`, `wp_loop_list`, and `wp_nested_loop` (`ProofLib/SepLogic/LoopTactics.lean`).
- **Framed `sepPost` composition:** `SepWP.frame_sepPost`, `SepWP.bind_sepPost`, `SepWP.done_sepPost`, and panic-aware `SepWPp.bind_sepWP`, `wpp_call`, and `wpp_call_frozen` (`ProofLib/SepLogic/WP/ControlTactics.lean`, `ProofLib/SepLogic/WPFrozen.lean`).
- **Well-founded loops & back-edge peeling:** `SepWP.loop_wf` (`SepWP.loop_wf_simple` for ghost-independent `post : State → SepProp → Prop`) keeps the back-edge continuation in context for single-pass verification of rotated (`do-while`) and multi-exit loops; per-iteration spatial frame peeling `F_peel` (`emp` default) is provided on `SepWP.loop_back`.
- **Bounded counter, list-cursor peeling, and multi-cutpoint CFG combinators:** `SepWP.loop_nat_cps`, `SepWP.loop_list_peel_cps` (peeling `F_peel` across `hcons`), `SepWP.loop_list_peel_latch` (two-cutpoint `head_pc` + `latch_pc` list peeling), and `SepWP.cfg_fixpoint_wf_cps`.
- **Panic-aware (`SepWPp`) counterparts:** `SepWPp.loop_wf` (`SepWPp.loop_wf_simple`), `SepWPp.loop_back` (peeling `F_peel` across both `Q` and `Qp`), `SepWPp.loop_nat_cps`, `SepWPp.loop_list_peel_cps`, and `SepWPp.cfg_fixpoint_wf_cps`.

### 2. `ProofLib/Hoare/Safety.lean` (`Role::Proof`)
Bridges total correctness (`reaches_stop`, `subroutine_ok`), first-stop `StepsUntil (SubroutineStop s0)` adequacy, and step-indexed partial correctness (`safe_until`, `safe_until_pc`, `safe_reaches`, `safe_subroutine_ok`):
- **Total-to-Partial Adequacy:** `reaches_stop.to_safe` and `subroutine_ok.to_safe` derive partial correctness + memory safety with the **exact same postcondition / `Spec`**.
- **First-Stop `StepsUntil (SubroutineStop s0)` Adequacy:** `subroutine_ok.stepsUntil_of_sentinel_lr`, `raw_subroutine_ok.stepsUntil_of_sentinel_lr`, and `subroutine_ok.stepsUntil_of_unaligned_lr` strengthen the `Steps prog s0 sf` witness of `subroutine_ok` to `StepsUntil prog (SubroutineStop s0) s0 sf` whenever the entry return address `s0.readReg64 Reg.lr` is a universal-fetch-none return sentinel (`∀ m, prog.fetchMem m lr = none`, e.g. any 4-byte-unaligned address `lr.toNat % 4 ≠ 0`; the underlying helper `steps_eq_of_subroutineStop_sentinel_lr` only requires `prog.fetchMem sm.mem lr = none` at the stopping state `sm`), paired with the 0-step `SubroutineStop` collapse lemma `stepsUntil_subroutineStop_eq_self_of_lr_eq_pc` demonstrating why unconstrained `s0.lr = s0.pc` stops in 0 steps.
- **Direct Safety & Step Rules:** `safe_until_of_stepsUntil`, `safe_until_pc_of_stepsUntilPC`, `safe_until_pc_of_reaches_pc`, `subroutine_ok.safe`, `safe_until.step`, `safe_until.done`, `safe_until.prefix`.
- **Step-Indexed Weakest Preconditions:** `wp_idx` and `SepWP_idx` for verifying potentially non-terminating loops without a termination measure.

### 3. `ProofLib/Hoare/Hooks.lean` (`Role::Proof`)
Connects extern hooks (`Program.externAt?`) and relocatable ELF stubs to `subroutine_ok`:
- **Hook-to-Subroutine Lifting:** `subroutine_ok_of_hookOk`, `hook_ok_at_raw`, `hook_ok_at`, and `hook_ok_stub` prove `subroutine_ok` in 1 `Step.extern` step at PLT/GOT stub offsets.
- **Rust Panic Stubs:** `panic_at_panicSymbol` and `panic_at_hook` resolve `externAt?` under `Rust.withPanics` to `some Rust.panicked`.
- **Compositional `subroutine_ok` Combinators:** `subroutine_ok_map` (and panic-aware `subroutine_ok_map_panic`) change the ghost parameter type and frame; `subroutine_ok_refine_entails`, `subroutine_ok_refine_frame`, and `subroutine_ok_mono_sp` refine ghost state, local frame, and return SP equalities; `subroutine_ok_by_cases` case-splits on a ghost predicate `c : α → Prop`; `subroutine_ok_of_b` handles single-instruction tail-call trampolines (`B target`); `subroutine_ok_ofImage` and `library_ok_of_deps` lift rebased theorems to `Program.ofImage` and `library_ok`.

### 4. `ProofLib/LibcHooks.lean` & `ProofLib/Hoare/LibcHooks.lean` (both `Role::Proof`)
Splits reusable C/Rust runtime hook definitions from their `HookOk` soundness proofs. Both are untrusted, so trusted `Examples/*/Spec.lean` files cannot import them (they define campaign-local allocator models instead):
- **Call-Site-Indexed Symbolic Allocator (`ProofLib/LibcHooks.lean`):**
  - `ProofLib.Allocator`: maps `(callIdx : Nat, reqBytes : BitVec 64)` to a pointer (`0#64` on OOM), preventing aliasing across multiple allocations of the same size.
  - `Allocator.allocAt`, `Allocator.callocAt`, `Allocator.allocSeq`: spatial ownership predicates for uninitialized (`memRegion`) and zero-initialized (`↦ₛ List.replicate len 0#8`) heap allocations.
  - `libcFreeSpec` & `freeRegionSpec`: ownership-consuming `free(ptr)` contracts (no-op when `ptr = 0#64`, consumes `memRegion ptr n` otherwise).
- **Hook Transformers & `HookOk` Witnesses (`ProofLib/Hoare/LibcHooks.lean`):**
  - Leaf & field-query hook wrappers: `retHook`, `hookNoop`, `hookReturnZero` (`hookAllocNull`), `fieldHook`, `fieldHook64`, register readbacks (`retHook_writeReg64_x0`, `retHook_writeReg32_x0`), and soundness rules (`retHook_ok`, `regHook_ok`, `hookNoop_ok`, `hookReturnZero_ok`, `fieldHook_ok`, `fieldHook64_ok`).
  - Hook-stack bottom splitting & refolding: `stackAt_split_bottom_of_eq`, `stackAt_split_hook`, `stackAt_refold_bottom`.
  - Byte/region memory operations: `hookMemset`, `hookMemcpy`, `hookMemmove` and their `HookOk` proofs (`hookMemset_ok`, `hookMemset_region_ok`, `hookMemcpy_ok`, `hookMemcpy_region_ok`, `hookMemmove_ok`).
  - Concrete allocator witnesses for `HookSat`: single-slot pool (`witnessAlloc`, `mallocPoolHook`, `freePoolHook`, `witnessAlloc_ok`, `hookFree_ok`) and multi-allocation bump allocator (`bumpAllocator`, `bumpAllocReg`, `bumpAllocReg_step`, `satisfies_bumpAllocator_init`).

### 4a. `ProofLib/Hoare/HookMap.lean` (`Role::Proof`)
Satisfiability of extern-hook bundles. A `structure <Name>Hooks … (hooks) : Prop` with
`HookSat hooks "sym" spec` fields is vacuous if no hook table satisfies it (for example two fields
on the same symbol with contradictory specs), so campaigns prove `∃ H, <Name>Hooks … H`:
- `hookMap entries base` builds the table (first matching entry wins); `simp` with
  `HookSat_hookMap_cons_self` / `HookSat_hookMap_cons_of_ne` reduces each field to `HookOk f spec`
  (string literal inequalities are decided by `simp`).
- `HookSat_and_iff` / `HookSat.same_hook`: duplicate fields on one symbol need one hook meeting both
  specs, so a bundle is refuted from `¬ ∃ f, HookOk f s₁ ∧ HookOk f s₂`.
- `HookOk.mono`, `HookOk.comap`, `HookSat.mono`: consequence rules; `hookNoop_ok_of_entails` for
  read-only `preserves` contracts.

### 5. `ProofLib/Hoare/SubroutineHook.lean` (`Role::Proof`)
Lifts verified ARM64 subroutines and layout-generic multi-block placed library exports to deterministic `State → State` external hooks (`HookOk`):
- **Writable code-overlay lifting:** `Spec.liftedSubroutineHook`, `SepProp.NoRO`, `subroutineHook_ok_with_codeRegion`, and `subroutineHook_ok_readOnly` over `loadCodeMem` / `restoreCodeMem`.
- **Single-program `CodeLoaded` lifting (no `memRegion` or `SepProp.NoRO`):** `Spec.codeLoadedSubroutineHook`, `subroutineHook_ok_of_codeLoaded`, `subroutineHook_ok_codeLoadedSubroutineHook`, `SepWP.seq_codeLoaded`, and `SepWP.mono_codeLoaded`.
- **Multi-block `Obj.MultiPlacedLib` hook lifting & read-only (`↦ᵣ`) code bridges:**
  - `Obj.MultiPlacedLib.subroutineHook` (`Arm64.multiSubroutineHook`), `Obj.MultiPlacedLib.fnBlockIdx`, and `Spec.codeLoadedMultiSubroutineHook` (`Obj.MultiPlacedLib.codeLoadedSubroutineHook`).
  - `subroutineHook_ok_of_multiCodeLoaded` and `subroutineHook_ok_codeLoadedMultiSubroutineHook` lift `lib.subroutineOk fnName spec externs overrides` under `lib.Placeable mpl` to `HookOk (lib.subroutineHook mpl fnName externs overrides) ...`, auto-discharging the return-sentinel `externAt? (mpl.base i + 1#64) = none` obligation via `Obj.MultiPlacedLib.externAt?_base_add_one_noExterns` / `externAt?_base_add_one_of_pos`, threading `lib.CodeLoaded mpl` across all blocks via `Steps.keepsFrozen`, and forwarding `onOom` (`.allowOom`).
  - Under `lib.CodeLoaded mpl`, `loadCodeMem` / `restoreCodeMem` / `subroutineHookEntry` / `subroutineHookExit` leave `.mem` unchanged (`Obj.MultiPlacedLib.loadCodeMem_eq_of_codeLoaded`, `restoreCodeMem_eq_of_codeLoaded`, `subroutineHookEntry_mem_of_codeLoaded`, `subroutineHookExit_mem_of_codeLoaded`), so caller frames and invariants holding read-only (`↦ᵣ`) code ownership (`Obj.MultiPlacedLib.blockCodeRO`, `Obj.MultiPlacedLib.codeRO`) compose directly with zero `SepProp.NoRO` restriction. `Obj.MultiPlacedLib.satisfies_codeRO_of_codeLoaded`, `codeLoaded_of_codeRO`, and `codeLoaded_iff_codeRO` bridge `lib.CodeLoaded mpl m` and `lib.PermsRX mpl m ∧ (m ⊨ lib.codeRO mpl)`.
  - `SepWP.seq_multiCodeLoaded` and `SepWP.mono_multiCodeLoaded` thread `lib.CodeLoaded mpl` across `SepWP` execution.
- **Linux `SYS_MMAP` (`svc #0`) `SepWP` step rules:** `SepWP.step_svc_mmap` and `SepWP.step_svc_mmap_fixed_protNone`.

### 5a. `ProofLib/Hoare/MultiCodeROHook.lean` (`Role::Proof`)
Standalone leaf module (not re-exported by `ProofLib/Hoare.lean`) lifting verified `Obj.MultiPlacedLib` subroutines to `HookOk` backed purely by read-only (`↦ᵣ`) code ownership `lib.codeRO mpl` in `SepProp`:
- **Multi-block code overlay & restoration:** `loadMultiCodeMem`, `restoreMultiCodeMem`, `multiCodeROHookEntry`, `multiCodeROHookExit`, `Obj.MultiPlacedLib.codeROSubroutineHook` (`Arm64.multiCodeROSubroutineHook`), and `Spec.codeROMultiSubroutineHook` (`Obj.MultiPlacedLib.codeROSubroutineHookSpec`) overlay all code blocks as `Perm.rx` on hook entry and restore `s0.mem.cells` across all blocks on hook exit.
- **Pure `codeRO` lifting (no `PermsRX`, `CodeLoaded s0.mem`, or `SepProp.NoRO`):** `subroutineHook_ok_of_multiCodeRO_at`, `subroutineHook_ok_of_multiCodeRO_framed`, `subroutineHook_ok_of_multiCodeRO`, and `subroutineHook_ok_codeROMultiSubroutineHook` preserve caller frames and state-indexed invariants across both `.Running` and `.OutOfMemory` when the surrounding environment transports invariants without constraining `s.mem.perm`.

### 6. `ProofLib/Hoare/OracleHook.lean` (`Role::Proof`)
Monadic and oracle-valued symbol hooks (`OracleExterns M := String → Option (State → M State)`) for any `[Monad M] [LawfulMonad M]`:
- **Oracle-hooked execution:** `Program.oracleHookAtOff?`, `Program.oracleExternAt?`, `stepStateWithOracle`, `execUntilPCWithOracle`.
- **Pure handler bridge (`PureOracleHandler M H`):** `OracleExterns.withHandler`, `OracleExterns.KeepFrozen`, `Program.hookAtOff?_withHandler`, `simulateQ_execUntilPCWithOracle`, `KeepFrozen.hooksKeepFrozen`, plus a built-in indexed free oracle monad `FreeOracle` (`OracleFamily`, `FreeOracle.query`, `FreeOracle.simulate`).
- **Counted oracle runs:** `RunsToAt`, `RunsTo`, `RunsToAt.refl`, `RunsToAt.step`, `RunsToAt.weaken`, `RunsToAt.trans`, `RunsToAt.seq`, `RunsTo.done`, `RunsTo.hook`, `RunsTo.mono`, `RunsTo.exec`, `Program.oracleHookAtOff?_eq_none`, `RetAway`, and the `oracle_step` tactic.

### 7. `ProofLib/Hoare/SubroutineOk.lean` (`Role::Proof`)
Intermediate Hoare judgments (`reaches_pc`, `code_ok`, `Program.rawSubroutineOk`, `raw_subroutine_ok`) and trace-agnostic outcome combinators for `subroutine_ok` and `reaches_outcome` (the partial-correctness judgments `safe_reaches`, `safe_subroutine_ok`, `SafeFnPtrSpec`, `Program.safeSubroutineOk` are trusted and defined in [`Arm64/Trusted/Spec/Hoare.lean`](../../Arm64/Trusted/Spec/Hoare.lean)):

### 8. `ProofLib/Hoare/TraceEq.lean` (`Role::Proof`)
Traced-primary contracts: prove `subroutine_ok P e (Spec.withTraceEq spec)` once (`wp_done` discharges `sf.trace = s0.trace` along non-`svc` paths), then derive the untraced contract with `subroutine_ok.of_withTraceEq` / `Program.subroutineOk.of_withTraceEq` / `Program.relocSubroutineOk.of_withTraceEq`. Hook contracts lift with `HookSat.with_trace_eq` under the explicit hypothesis `HooksPreserveTrace hooks`. There is deliberately **no** lemma deriving the traced contract from the untraced one plus a "no `svc` reachable from the entry" check: `subroutine_ok` lets the witness run return to the caller, execute caller code (including `svc`), and come back to `lr`, so such a lift is unsound (the counterexample is in the module docstring).

#### `ProofLib/Hoare/WithPure.lean` (`Role::Proof`)
Strengthened-primary contracts: prove `subroutine_ok P e (Spec.withPure spec R)` once, then derive the plain contract with `subroutine_ok.of_withPure` (and the `Program.subroutineOk` / `Program.relocSubroutineOk` forms). `Spec.withTraceEq spec` is `Spec.withPure spec (fun s0 sf => sf.trace = s0.trace)`; the same unsoundness argument rules out deriving `R` from the plain contract by a code check.
