# `ProofLib/Testing/`: ProofLib Tactic & Spec-DSL Tests

`ProofLib/Testing/` holds untrusted tests (`Role::Test`) for `ProofLib/` automation and the spec-audit tooling. It belongs to the untrusted `Testing` Lake library (root `ProofLib.Testing`, umbrella [`ProofLib/Testing.lean`](../Testing.lean)); nothing trusted imports it.

Sibling test trees: [`Arm64/Testing/`](../../Arm64/Testing/README.md) (ISA/decoder/loader tests) and `CaseStudies/<Campaign>/Testing/` (per-campaign spec audits). `timeout 1200 lake build --no-ansi Testing` builds the shared test suites; it is required when editing shared `ProofLib/` tactics or linters.
