# Denied defining-module patterns for `Symbolic/scripts/machine_free_check.py`.
#
# Format:
#   - `[group <id>]` starts a machine-parsed pattern group (`--exclude-deny-group <id>` omits
#     that group's patterns; comments are never used for group membership).
#   - One exact module (`Foo.Bar.Baz`) or module-prefix wildcard (`Foo.Bar.*`, matching both
#     `Foo.Bar` and `Foo.Bar.<submodule>`) per line.
#   - `#` starts a comment. Empty lines are ignored; malformed lines fail closed.
#
# Classification uses `env.getModuleIdxFor? c -> env.header.moduleNames[idx]`,
# never the constant's name prefix. A constant defined in a denied module FAILs the check unless
# it has an exact entry in `machine_free_allow.txt` (or `--allow-file`); the walk descends into
# allowed constants too.
#
# What this check does not see: numerals that the `asm%` / `asm64%` / `asm8%` elaborators inline
# from `AsmConstants` at elaboration time leave no constant behind. Layout literals in statements
# are covered by the SPEC-KEY guards, not by this check.
