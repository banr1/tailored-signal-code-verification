# Allow-list of constants for `Symbolic/scripts/machine_free_check.py`.
#
# Nothing may be added without careful review and sign-off.
# Format per entry (one per line; `#` at start of line begins a comment):
#   <Constant.Name> : <non-empty one-line reason>
#
# Scope: the trusted symbolic CLI statement modules
#   Symbolic.Specifications.Refinement.{Statement,CliSetup,RefinementPreservation} and
#   Symbolic.Specifications.Security.AsmSecure
# (`Refinement.ElfBinding` is ELF-level by design and is not claimed machine-free).
# Every constant below is defined in `arm64-semantics` (denied `Arm64.*`) and was signed off one by
# one, against its definition read at engine submodule c2ef2f44e (ISA/State.lean, Process/Types.lean,
# Process/Loader.lean, Object/Reloc.lean; Arm64.Obj.pageSize is defined in Object/Reloc.lean).
#
# Walk the sign-off assumed: types and def/opaque/theorem values; inductive -> constructors and its
# mutual block; constructor -> inductive; recursor -> rules and block; a raw `Expr.proj` counts as a
# use of that projection; the `match_` / `proof_` / `below` auxiliaries of the four modules are
# roots too; the walk descends into allowed constants, and the 60 below are closed under it.
#
# Verdicts:
#   [SIGN]  pure file-system / process-input data and functions.
#   [INERT] only a default value that is built but never read (the default `init : ProcessInit` field
#           of `ProcessInputs`, which holds the default oracle, auxv, stack and physMemAvail fields). This is
#           enforced because no projection, `casesOn` or recursor of these types is on the list, so
#           any read of them FAILs.
# Never add: ProcessInputs.{argv,envp,execfn,init}, the reducible forwarders
# ProcessInputs.{auxv,stackTop,stackSize,physMemAvail,oracle} (= `i.init.<field>`), ProcessInputs.rec / casesOn,
# any ProcessInit.* / Oracle.* / AuxvConfig.* / Timespec.* projection, recursor or casesOn (e.g.
# ProcessInit.{auxv,stackTop,stackSize,physMemAvail,oracle,rec,casesOn}); Arm64.State, its
# projections and any other register, memory or CPU constant of ISA.State; ElfImage.loadState /
# loadElf or any other ELF-loading constant of Process.Loader.
# Re-check every entry on each engine submodule bump.
